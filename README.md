# Numerologia

Um sistema de estudo sobre numerologia, feito para auxiliar buscadores de conhecimento, misticismo e espiritualidade a obterem mais compreensão da vida e aprofundarem o autoconhecimento.

A partir do nome e da data de nascimento, o sistema apresenta um mapa numerológico com interpretações, características pessoais e ciclos da vida. Também permite explorar relacionamentos e consultar períodos pessoais.

**[Acessar o sistema pelo GitHub Pages](https://siteprofissional1.github.io/numerologia/)**

## Como usar

Abra o arquivo `index.html` no navegador, informe seu nome completo de nascimento e sua data de nascimento e clique em **Gerar mapa numerológico completo**. Você pode consultar os resultados e usar **Imprimir / Salvar como PDF** para guardar o mapa.

## Aviso

Este sistema tem finalidade de estudo e reflexão. Não substitui tratamento médico, acompanhamento profissional nem métodos científicos.
